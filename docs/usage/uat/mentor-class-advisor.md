# UAT: Mentor / Class Advisor
Login `class_advisor@sxcce.example.edu`. Guide: roles/mentor-class-advisor.md.

| # | Step | Expected |
|---|---|---|
| 1 | `/campus-portal/faculty/mentees` | Your mentees listed |
| 2 | Open a mentee, add a note (Category, Notes, follow-up date), **Add note** | Note appears in Counselling notes |
| 3 | Add a note with Confidential ticked | Marked Confidential; visible to you |
| 4 | Student Services > Reports > Attendance Shortage | Students under the attendance minimum listed |
| 5 | Student Services > Attendance > Student Leave Application | CSE leaves (medical, on duty) with certificate |
| N1 | Open the same mentee's confidential note as `faculty@` | Not visible |
| N2 | Open a student of another class as mentees | Refused: not your mentee |
| N3 | Student Services > Records & Certificates > Student, Condonation Request | No **Add** button; condonation requests are read-only for you |
