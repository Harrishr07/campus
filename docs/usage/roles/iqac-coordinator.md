# IQAC Coordinator

**Login (demo):** `iqac@sxcce.example.edu`

**What you do:** collect evidence and data for NAAC / NBA / AQAR / AISHE, run feedback, track committees.

**You see (desk):** IQAC, Academics, Academic Governance, Faculty, Labs, Research, Approvals.

## Daily tasks
1. **Accreditation cycle:** IQAC > Accreditation > Accreditation Cycle (AQAR 2025-26); Metric Value, Evidence.
2. **Readiness:** IQAC > Reports > Cycle Readiness; Metric Drill-down.
3. **Run checks:** Validation Run.
4. **Feedback:** IQAC > Feedback > Feedback Form, Feedback Campaign; IQAC > Reports > Feedback Analysis (docs/usage/feedback.md).
5. **Committees:** Academic Governance > Meetings > Body Meeting; IQAC > Reports > Committee Compliance, IQAC Action Taken Report.
6. **Regulator deadlines:** Regulator Submission; Reports > IQAC Calendar.
7. **Outcome attainment:** Academics > Reports > CO Attainment by Course, PO Attainment by Program.
